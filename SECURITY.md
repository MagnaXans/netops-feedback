# Security Policy for NetOps Studio

NetOps Studio is committed to the security of its client-side network diagnostic and analysis workbench. We appreciate responsible disclosures from researchers and users.

## Scope
This policy covers the web applications and tools hosted at [netopsstudio.net](https://netopsstudio.net).

### In Scope
- Client-side data leaks or DOM security flaws
- Cross-Site Scripting (XSS)
- Content Security Policy (CSP) bypasses
- PII sanitization or parser bypasses in diagnostic tools

### Out of Scope
- Denial of Service (DoS / DDoS) attacks against Cloudflare edge infrastructure
- Social engineering or phishing attempts against maintainers
- Automated scanner spam without demonstrable impact

## Reporting a Vulnerability
Please **do not** open public GitHub issues for security vulnerabilities.

Instead, submit your report privately through our GitHub Advisory portal:
👉 **[Report a Vulnerability Privately](https://github.com/MagnaXans/netops-feedback/security/advisories/new)**

Reports submitted through this form are confidential and sent directly to the maintainers. We aim to acknowledge receipt of genuine vulnerability reports within 48–72 hours.
