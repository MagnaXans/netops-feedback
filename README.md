# NetOps Studio Community & Feedback

> Public community forum, issue tracking, and feature requests for NetOps Studio.

Welcome! This repository is dedicated to gathering feedback, tracking bug reports, and discussing new feature ideas for [NetOps Studio](https://netopsstudio.net).

## How to Contribute

- **Report a Bug:** Found an issue or incorrect CIDR calculation? Open a ticket in [Issues](../../issues) with reproduction steps.
- **Request a Feature:** Have an idea for a new networking tool or visualizer? Submit a proposal in [Discussions](../../discussions) or [Issues](../../issues).
- **Ask Questions & Share Feedback:** Join the conversation in [Discussions](../../discussions).
